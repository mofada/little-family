请设计一个移动端优先、PC 端也可查看的 H5 家族图谱网页初稿，主题是“家庭 AI 生日助手 / 家谱系统”。

一、设计目标

这是一个用于记录家族成员、生日、亲属关系和家族图谱的 H5 页面。用户可以查看家族关系树、今日生日提醒、成员详情、家族时间轴，并支持未来接入 AI 生成生日祝福、自动称呼、关系查询等功能。

整体风格要求：
- 温馨、有家庭感
- 适合中国家庭使用
- 简洁现代，不要太老气
- 移动端优先
- PC 端居中展示，最大宽度 430px 或 480px，类似手机 App 页面
- 色调：米白、浅棕、浅红、柔和蓝绿色，可带一点国风纹理
- 视觉关键词：家族、生日、亲情、纪念日、家谱、温暖、AI 助手

二、页面结构

请设计一个单页 H5，包含以下模块：

1. 顶部 Hero 区

内容：
- 标题：家族图谱
- 副标题：记录每一位家人，也记得每一个重要日子
- 右上角可以有一个“今日提醒”小图标
- 背景可以是淡淡的山水、梅花、纸张纹理、家族树枝线条

展示统计卡片：
- 家族成员：34 人
- 家族分支：彭家 / 莫家 / 唐家 / 田家 / 曾家 / 何家 / 肖家 / 谢家 / 任家
- 今日生日：1 人
- 即将生日：3 人

2. 今日生日提醒卡片

卡片标题：
🎂 今日生日

内容示例：
- 曾芷琪｜侄女｜15岁
- 农历三月二十七
- 所属家族：曾家

按钮：
- 生成生日祝福
- 复制 AI Prompt

按钮风格要醒目，但不要太商业化。

3. 家族图谱模块

标题：
家族关系图谱

移动端设计要求：
- 不要画特别复杂的大树，优先做“横向滑动家族树”
- 每一代分层展示：第一代、第二代、第三代、第四代
- 节点用小卡片展示
- 男性用浅蓝色头像/标签
- 女性用浅粉色头像/标签
- 配偶关系用横向线连接
- 父子/母子关系用竖线连接
- 支持横向滚动
- 当前用户“莫发达”节点高亮
- 今日生日成员节点显示小蛋糕标记

节点卡片内容：
- 姓名
- 关系
- 出生年份
- 生日：农历/阳历 月日
- 家族标签

示例节点：
唐贵娥｜外婆｜1933｜农历10月3日｜彭家
莫新付｜爸爸｜1970｜农历1月13日｜莫家
彭四英｜妈妈｜1968｜农历5月15日｜彭家
莫发达｜弟弟｜1997｜农历3月28日｜莫家
任蝉｜弟媳｜1998｜农历5月3日｜任家
曾芷琪｜侄女｜2011｜农历3月27日｜曾家

4. 成员详情弹层 / 卡片

点击成员节点后，出现底部弹层或详情卡。

内容：
- 姓名：曾芷琪
- 昵称：豆豆
- 关系：侄女
- 家族：曾家
- 性别：女
- 年龄：15岁
- 生日：2011年农历3月27日
- 父母：曾荣华 / 彭菲
- 所属代际：第四代

操作按钮：
- 生成生日祝福
- 查看关系路径
- 编辑资料

5. AI 生日助手模块

标题：
AI 生日助手

说明：
根据年龄、关系、性别和家族群风格，自动生成适合微信群发送的生日祝福。

展示一个 Prompt 预览框：

请模仿中国家庭微信群生日祝福风格生成文案。
要求：
- 温馨自然
- 不要太正式
- 适合发亲戚群
- 带 emoji
- 可以带微信表情：[蛋糕][庆祝][玫瑰]
- 不同年龄层语气不同

今天生日的人：
姓名：曾芷琪
称呼：侄女
性别：female
年龄：15

按钮：
- 复制 Prompt
- 生成祝福
- 查看历史祝福

6. 家族时间轴模块

标题：
家族时间轴

展示方式：
竖向时间轴，移动端清晰。

示例：
- 1933 唐贵娥出生
- 1959 彭前进出生
- 1968 彭四英出生
- 1970 莫新付出生
- 1983 彭丽出生
- 1997 莫发达出生
- 2011 曾芷琪出生
- 2023 谢子怡出生

7. 家族关系查询模块

标题：
关系查询

设计一个轻量查询卡片：
- 选择成员 A
- 选择成员 B
- 按钮：查询关系

示例：
莫发达 → 曾芷琪
结果：
曾芷琪 是 莫发达 的侄女
关系路径：
莫发达 → 彭菲 → 曾芷琪

8. 底部导航

移动端底部 Tab：
- 首页
- 图谱
- 生日
- 时间轴
- 我的

底部导航固定在底部，适合 H5。

页面将基于如下数据结构渲染：

interface FamilyMember {

四、交互设计

请体现以下交互：
- 家族图谱可横向滑动
- 点击成员节点打开详情
- 今日生日成员高亮
- 可复制 AI Prompt
- 可切换农历/阳历显示
- 可按家族筛选：全部、彭家、莫家、唐家、田家、曾家、何家、肖家、谢家、任家
- PC 端居中展示移动端容器，两侧留白

五、视觉细节

- 使用圆角卡片
- 头像可以用男女默认插画头像
- 男性节点浅蓝色，女性节点浅粉色
- 今日生日节点加蛋糕 icon
- 配偶关系用心形小图标连接
- 父子关系用简洁线条连接
- 背景有轻微宣纸纹理或淡色渐变
- 标题可使用偏国风但清晰的字体
- 正文用现代无衬线字体
- 不要太复杂，不要像企业后台，要像一个温暖的家庭小程序

六、首屏重点

首屏必须看到：
- 家族图谱标题
- 今日生日提醒
- 家族成员统计
- 进入图谱的入口

七、输出要求

请输出一个高保真 H5 页面设计稿，优先移动端 390px 宽度，同时给出 PC 端查看效果。整体要像一个可以直接开发成 Vue3 H5 应用的页面。
